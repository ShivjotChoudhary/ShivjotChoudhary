### 🛡️ SpamShield AI — Spam Detection Web App ⭐ NEW
> Full-stack Machine Learning web application that classifies messages as Spam or Not Spam using NLP.

- 🧠 **ML Model:** Multinomial Naive Bayes + TF-IDF Vectorization
- 📊 **Accuracy:** ~98% | Cross-validation (5-fold): ~97%
- 🗄️ **Database:** MongoDB Atlas — logs every scan with timestamp
- ⚡ **Uptime:** GitHub Actions + UptimeRobot — app never sleeps
- 🚀 **Deployed:** Live on Render
